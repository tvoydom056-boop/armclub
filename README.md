# Армрестлинг-клуб (MVP)

Кликер про армрестлинг по мотивам Punch Club: бои с колоритными соперниками, магазин прокачки как в Burrito Bison, вид от первого лица. План и ресёрч — в [docs/](docs/).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # правила матча + баланс на ботах
npm run build    # проверка типов + продакшен-сборка в dist/
```

## Как играть

- **Мышь / ПРОБЕЛ** — давишь руку. Спам тратит выносливость, пауза её восстанавливает.
- **1 · 2 · 3** (или кнопки внизу) — крюк · топролл · пресс. Смена техники даёт короткий штраф.
- Техники замкнуты в круг: **топролл бьёт крюк → крюк бьёт пресс → пресс бьёт топролл**. Пресс силён, только когда ты уже впереди.
- Соперник **выдаёт смену техники лицом** (оскал, брови вниз, значок над головой) — переключись раньше, чем он закончит.
- Не жми до «ГО!»: два предупреждения — фол и проигрыш раунда. Фол не даёт монет и не снимает перетрен; обычное поражение по-прежнему приносит часть награды и сбрасывает перетрен.
- Под шкалой руки показан остаток времени. Через 75 секунд исход решает перевес; ровно в центре побеждает игрок.
- Золотая отметка на шкале — порог сильного пресса с учётом прокачки плеча. У отметки и левее множитель позиции ×1,25, правее — ×0,65. Это один из множителей силы, помимо контртехники и штрафа переключения.
- **M** или кнопка 🔊 — звук вкл/выкл; громкость — ползунок в хабе. Звуки синтезируются в коде (`src/audio/`), файлов нет.
- Монеты открывают снаряды и качалку. Характеристики растут за опыт в тренировочных мини-играх; прогресс сохраняется в localStorage.
- Ошибки в тренировке дают слабую награду. Подход без единого нажатия не даёт опыта и не увеличивает перетрен.

## Первый этап улучшений: понятные правила и награды

В разделе карьеры есть раскрываемая памятка «Первый бой? Как побеждать». Подсказки в матче с Борей следуют четырём действиям: дождаться старта, удержать контртехнику, восстановить выносливость и использовать пресс из сильной позиции. Их можно скрыть в бою и включить в памятке; настройка сохраняется отдельно от прогресса.

После матча показываются до двух наблюдений по его фактическим метрикам: время с низкой выносливостью, под контртехникой, со слабым прессом или в переходе между техниками. Это подсказки для следующей попытки, а не доказательство причины поражения. Метрики обнуляются перед каждым матчем и не попадают в сохранение карьеры.

Реализация: `src/core/match.ts`, `src/core/matchAdvice.ts`, `src/ui/MatchHud.tsx`, `src/ui/MatchCoach.tsx`, `src/ui/TrainingGame.tsx`. Регрессионные сценарии добавлены в `src/core/matchAdvice.test.ts`, `src/store/game.test.ts`, `src/ui/trainingIntegration.test.ts`. При внесении этапа тесты, типы, линтинг, сборка и игровой прогон не запускались: проверка исполнения остаётся отдельной задачей.

## Лиги и турниры

В версии 2 карьера состоит из трёх лиг: подвальная (Боря и Лёва), городская (Дэнч и Виталик), профессиональная (Илья и Эрмес).
Тренируйся и победи обоих соперников в отборе, затем выиграй полуфинал и финал турнира подряд. Кубок открывает следующую лигу и даёт разовый бонус: 60, 120 или 200 монет.
Поражение или выход завершает попытку; прокачка, монеты, отбор и завоёванные кубки остаются. Между боями турнира нельзя тренироваться или покупать снаряды.
Завершённый полуфинал сохраняется после перезагрузки. В уже открытые лиги можно возвращаться для обычных боёв. Третий кубок завершает карьеру.
Старые сохранения сохраняют доступ к уже достигнутым лигам. Состав и награды — в `src/core/leagues.ts`.

Проверки карьеры: `npx vitest run src/core/leagues.test.ts src/core/save.test.ts src/store/game.test.ts`.
Проверка интерфейса: `npx playwright test --config playwright.leagues.config.mjs`.

## Устройство

```
src/core/    чистая логика без React и Phaser: match.ts (шаг симуляции), upgrades, opponents, techniques (+ тесты)
src/game/    Phaser: сцена матча, рисование рук/лиц векторной графикой в коде, фон и стол как SVG (staticArt.ts)
src/store/   Zustand: сохранение (game.ts) и снимок матча для интерфейса (hud.ts)
src/ui/      React: хаб, магазин, HUD матча, экран результата
```

Баланс — в `TUNING` (`src/core/match.ts`); после правок смотри таблицу винрейтов: `npx vitest run -t "таблица" --reporter=verbose`.

В dev-режиме сцена доступна как `window.__arm` (удобно для отладки).
