## 1. Видение

Карьера армрестлера от подвального бара до мирового супер-матча. Сидим за столом напротив соперника (вид от 1-го лица): видно его лицо и торс, нашу руку и замок кистей. В MVP матч — кликер: кликами давим руку, следим за выносливостью, ловим рывки соперника. Между матчами — магазин прокачки. Позже — система техник по «треугольнику» (хук / топролл / пресс / King's Move).

## 2. Кор-луп MVP

```
матч (20–60 с) → награда (монеты + слава) → магазин апгрейдов → следующий соперник → босс лиги → новая лига
```

## 3. Механика матча (MVP)

**Состояние:** `position ∈ [-1; +1]` (−1 — нас положили, +1 — мы положили), `stamina`, `oppStamina`, `phase: ready | go | fight | pin | foul`.

**Каждый тик:** позиция сдвигается на `(наша сила − сила соперника) × dt` с поправкой на рычаг.
- Наша сила = импульсы кликов (`clickPower × staminaFactor`, быстро затухают) + «статика» (пассивное усилие от апгрейда).
- Каждый клик тратит выносливость, без кликов она восстанавливается → важен ритм, а не голый спам.
- Сила соперника = база + рывки с «телеграфом» за 0.5–1 с (лицо, плечо, дыхание) + усталость.
- Рычаг: у того, кто ведёт, растёт преимущество — у самого пэда отыграться почти нельзя, как в реальном армрестлинге.

**Старт:** «Ready… Go!». Клик до «Go» — предупреждение (2 = фол, 2 фола = проигрыш раунда, как в WAF). Клик в окне ~150–250 мс после «Go» — бонус «взрывной старт».

**Раунды:** до 2 побед (bo3) в первых лигах, до 3 (bo5) у боссов; между раундами — выбор усиления.

**Активные способности (кулдауны):** «Рывок» (×3 к силе клика на 3 с), «Второе дыхание» (восстановить выносливость), «Мёртвая хватка» (2 с не отдаём позицию).

## 4. Прокачка (магазин в духе Burrito Bison)

Цена уровня: `base × 1.15^level` (подгоняем в таблице баланса).

| Апгрейд | Эффект в MVP | Потом (фаза 5) |
|---|---|---|
| Бицепс | + сила клика | Хук |
| Хват (пальцы) | + «статика», − шанс срыва | Атака и защита пальцев — топролл |
| Запястье (каппинг) | − сила рывков соперника | Контроль запястья |
| Выносливость | + запас и восстановление | Затяжные матчи, King's Move |
| Взрывной старт | Шире окно и больше бонус на «Go» | Флеш-пин |
| Магнезия (расходник) | Матч без срывов | — |

- Мета-петля: за каждую покупку звезда; 20 звёзд — бесплатная «спортивная сумка» (монеты, расходники, косметика).
- В фазе 5 апгрейды раскладываются на реальные компоненты: пронация, супинация, каппинг, райзинг, бэк- и сайд-прешер, трицепс и плечо.

## 5. Соперники и лиги

- Лиги-локации (как в Punch Club): **Подвал-бар → Качалка → Областной турнир (правила WAF) → Нацчемпионат → Супер-матч**. В MVP — 2 лиги.
- В лиге 4–5 соперников и босс. Карточка соперника (коллекция, как на скрине 2): портрет, имя-пародия, описание, стиль (в MVP только визуально), статы, награда.
- У каждого 1–3 паттерна с «телеграфом» (подход Punch-Out!!): игрок изучает соперника, а не только качает цифры.
- Прошлых соперников всегда можно перепройти → нет тупиков в прогрессе.

## 6. Экран матча (вид от 1-го лица, правая рука)

```
+----------------------------------------------------------------+
| Лига: Подвал   Раунд 1 (до 2 побед)      монеты 1 250   * 7/20 |
|                                                                |
|                          ( лицо )   <- эмоции + телеграф        |
|                     ____/ торс  \____                           |
|                    /  плечи       пег \  <- его свободная рука  |
|   [пин-пэд]               \\  ##  //                [пин-пэд]   |
|   <-- ПОБЕДА               \\ ## //  замок кистей  ПОРАЖЕНИЕ -->|
|  ===========================[локоть]============= стол ======== |
|                                   \\                            |
|                                    \\  наше предплечье         |
|                                     \\ (входит снизу)          |
| ПОЗИЦИЯ  <=====================|...........................>   |
| ВЫНОСЛ.  [########.....]           [Рывок] [2-е дыхание]        |
+----------------------------------------------------------------+
```

**Риг:** `position` → угол замка θ ≈ ±80° вокруг точки между локтями. Каждое предплечье — спрайт, повёрнутый от своего локтя к точке замка; спрайт кистей поворачивается вместе с θ, а в фазе 5 меняет кадры под технику.

## 7. Архитектура

```
src/
  core/            чистый TS без React и Phaser: правила и баланс (покрыто Vitest)
    match.ts         step(state, input, dt) → state
    opponents.ts     данные соперников и паттерны
    upgrades.ts      апгрейды и формула цены
    save.ts          сохранение + версия схемы
  store/           Zustand (vanilla) — единый источник правды для React и Phaser
  game/            Phaser: сцена матча, риг рук, эффекты
  ui/              React: меню, магазин, карточки, HUD
```

Принцип: Phaser только рисует состояние, правила живут в `core/`. Тогда техники (фаза 5) — это расширение `core/` и новый арт, без переписывания сцен.

## 8. Фазы

Размеры: S — 1–2 рабочие сессии, M — 3–5, L — 6+, XL — отдельный проект внутри проекта.

### Фаза 0 — Каркас (S)
- Проект из `phaserjs/template-react-ts`, плюс Zustand, Vitest, ESLint и Prettier, git.
- **Готово, когда:** `npm run dev` показывает пустую сцену Phaser с React-оверлеем, `npm test` зелёный.

### Фаза 1 — Матч на «серых коробках» (M)
- `core/match.ts`: силы, выносливость, позиция, Ready-Go, фальстарт, пин.
- Риг из прямоугольников в ракурсе от 1-го лица — проверяем камеру сразу, до арта.
- Один соперник с рывками и телеграфом (пока — мигающий прямоугольник).
- Дебаг-панель со слайдерами (сила, выносливость, рычаг) для тюнинга на лету.
- **Готово, когда:** матч можно и выиграть, и проиграть руками; тесты на ядро: без кликов проигрываем за N с, клик до «Go» даёт предупреждение, при заданной силе победа за ~X с.

### Фаза 2 — Экономика и магазин (M)
- Монеты, 5–6 апгрейдов, формула цен, магазин (сетка с уровнями, как на скрине 2), звёзды → сумка.
- Лига 1: 4–5 соперников и босс; сохранение в localStorage.
- Таблица баланса (Google Sheets или Excel) на первые 30 минут игры.
- **Готово, когда:** новый игрок проходит лигу 1 за 20–30 минут; перезагрузка страницы не теряет прогресс.

### Фаза 3 — Вид от 1-го лица: арт v1 и «сочность» (L)
- Фон-локация, стол, соперник (покой / напряжение / ухмылка / поражение), предплечья, замок кистей.
- Телеграфы рывков в анимации соперника; тряска, hit-stop, всплывающие цифры, частицы, звуки.
- **Готово, когда:** 10-секундный клип без пояснений читается как «я борюсь на руках с мужиком напротив».

### Фаза 4 — Карьера и мета (M–L)
- 2-я лига, раунды bo3 / bo5 с выбором усиления в перерыве, активные способности, коллекция карточек соперников, короткое интро-пародия.
- **Готово, когда:** вертикальный срез на 1–2 часа игры, который не стыдно показать друзьям.

### Фаза 5 — Техники по «треугольнику» (XL, отдельный SPEC)
- Позиция становится многомерной: угол пина, угол запястья (каппинг ↔ флоп), высота кисти (райзинг), пронация ↔ супинация, дистанция (тяга на себя).
- Техники — узлы графа (H1–H3, P1–P2, T1–T4, KM) с требованиями к статам, переходами и контрами.
- Развилка, которую решаем в SPEC: управление техникой в реальном времени (клики = сила, клавиши или свайпы = смена техники) или в стиле Punch Club — план техник перед раундом, автобой и вмешательство кликами.
- ИИ соперника выбирает техники с телеграфом.
- Арт: сначала 3 семейства (хук / топролл / пресс), потом варианты; предплечья — скелетная анимация, замок кистей — набор поз на каждую технику с плавными переходами между ними.
- Лиги с разными правилами (King's Move разрешён только в подвале).
- **Готово, когда:** более сильного соперника можно победить правильно выбранной контр-техникой.

### Фаза 6 — Полировка и релиз (M)
- Музыка, настройки (громкость; удержание кнопки вместо частых кликов — бережём руки игрока), плейтесты, баланс.
- Деплой на itch.io или GitHub Pages; опционально — десктоп или мобилки через Tauri / Capacitor.

## 9. Риски

| Риск | Что делаем |
|---|---|
| Кликер быстро надоедает (только спам) | Ритм через выносливость, телеграфы, активные способности; в фазе 5 — техники |
| Арт съедает всё время | Серые коробки до фазы 3; риг вместо покадровой анимации; скелетная анимация и позы кисти для техник |
| Взрыв числа поз (техника × техника) | Риг и 3 семейства вместо 11 × 11 наборов кадров |
| Баланс «на глаз» | Таблица баланса, дебаг-слайдеры, тесты на `core/` |
| Phaser 4 молодой, туториалов мало | Сверяемся с официальной документацией v4; логика не зависит от движка |
| Права и IP | Только пародийные имена, свой арт, ассеты с проверенной лицензией |

## 10. Открытые решения
