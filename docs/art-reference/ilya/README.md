# Илья — набор спрайтов

Образ утверждён пользователем: короткие русые волосы, молодой атлет, чёрная спортивная майка с угловатыми серыми панелями. Манера — тёплая комиксная графика приложения.

Создано встроенным image_gen. Точные запросы, роли референсов и пути исходных генераций записаны в `prompts.json`. Исходные PNG сохранены в `output/character-concepts/ilya-full-v1/`; утверждённые тесты — в `output/character-concepts/ilya-tests-v1/`.

Рабочие файлы: `public/art/opponents/ilya/`.

Атлас читается слева направо, сверху вниз: левый пин → нейтральный кадр 4 → правый пин. Красный напульсник с одной белой полосой принадлежит игроку. Общий стол и фон используются из существующего набора.

Экспорт `export-sprites.ps1` приводит слои к размерам контракта и выравнивает рамки голов. Рисунок исходных PNG сохраняется. У всех файлов есть настоящий альфа-канал. Для исходных генераций внутренний альфа-канал может быть 253/255; это не мешает прозрачности вокруг силуэта.

`overview.png` — общий лист всех 11 игровых спрайтов. `poses-preview.png` и `pose-0.png` … `pose-8.png` — статические сборки за столом; это превью разделённых слоёв, предплечье игрока заканчивается на нижнем срезе ячейки. В основном приложении продолжение предплечья выполняет рендерер. `preview.html` переключает позы и выражения. HTML-превью не проверено в браузере: соединение с браузером в этой сессии не установилось. PNG-превью просмотрены.

Проверка размеров, RGBA, прозрачного фона, семи разных голов, девяти заполненных кадров и регистрации голов записана в `asset-validation.json`; максимальное смещение рамки головы — 0 px.

Набор упакован в `output/ilya-sprites.zip`. Параметры сборки для дальнейшего подключения — `rig.json`. Набор подготовлен как графические ресурсы; добавление Ильи в список игровых соперников и настройка его боя этой задачей не выполнялись.
