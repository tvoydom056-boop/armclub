# Ермес — набор спрайтов

Имя персонажа: **Ермес**, идентификатор: `ermes`.
Утверждённый образ из фотографии: короткие тёмные волосы с выбритыми боками, короткая щетина, чёрная футболка, массивные предплечья. Тестовый образ ранее сохранялся в `output/character-concepts/vitalik-tests-v2/`; этот набор продолжает именно его.

Порядок кадров атласа: слева направо, сверху вниз, от левого пина через нейтраль (кадр 4, нумерация от 0) к правому. В каждом кадре обе сцепленные кисти и предплечья составляют одно изображение. Красный напульсник с белой полосой относится к игроку.

## Просмотр и экспорт

- `gallery.html` — галерея спрайтов.
- `preview.html` — переключение девяти собранных поз и просмотр эмоций.
- `faces-preview.png`, `parts-preview.png`, `poses-preview.png` — статические обзоры.
- `pose-4.png` — нейтральная сцена.
- `../../../output/ermes-sprites.zip` — архив PNG с именем Ермес и настройками сборки.
- `generation-manifest.json` — полные промты, источники генераций и параметры экспорта.
- `generated/` — исходные изображения встроенного image_gen.

Экспорт выполняется `export-sprites.ps1`: размеры приводятся к шаблонам игры, исходники сохраняются. При упаковке атласа очищается пустая верхняя правая область кадров второго и третьего рядов, куда заходили срезы предплечий предыдущего ряда. Этот участок не содержит анатомии текущего кадра.

Превью собираются скриптами `render-contact-sheets.ps1` и `render-scenes.ps1`. Используются общий фон бара, стол, подушки и рука игрока из приложения. Свободная рука располагается за корпусом, как в сцене игры.

Все семь голов, отдельные слои и девять собранных поз проверены визуально. Проверены размеры PNG, прозрачность и чистота верхних областей кадров атласа. HTML-галерея использует локальные файлы; в браузере её не проверяли.

## Подключение

`character.json` содержит начальные настройки для `src/game/characters/ermes.json`; `rig.json` — настройки статических превью. Набор подготовлен для подключения. Состав соперников и настройки боя этой задачей не изменялись. Для добавления Ермеса следуйте `docs/adding-opponent.md` и проверьте крепления в редакторе рига и живой сцене.
