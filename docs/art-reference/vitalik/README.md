# Виталик — полный набор спрайтов

Утверждённый образ: короткие тёмные волосы, длинная густая борода, чёрная спортивная футболка, мощные предплечья.

Создано встроенным image_gen. Все промты, источники генераций и сведения о проверке сохранены в `generation-manifest.json`. Исходные PNG находятся в `generated/`; одобренные тесты — в `output/character-concepts/vitalik-tests-v1/`.

Папка для приложения: `public/art/opponents/vitalik/`. В ZIP — папка `vitalik/`.

Все PNG, кроме фона, имеют настоящий альфа-канал. Общие стол, подушки и свободную руку игрока берём из существующего набора приложения.

Атлас рук читается слева направо, сверху вниз: левый пин → нейтраль → правый пин. Нейтраль — кадр 4 при нумерации от нуля. В каждом кадре кисти и предплечья нарисованы одним непрерывным изображением; красный напульсник с белой полосой относится к игроку.

## Превью

- `gallery.html` — все спрайты, открывается локально.
- `preview.html` — переключение девяти собранных поз, открывается локально.
- `faces-preview.png` — семь состояний головы.
- `parts-preview.png` — отдельные слои.
- `pose-4.png` — нейтральная сцена.
- `poses-preview.png` — все девять собранных положений.

Параметры сборки превью находятся в `rig.json`. Использована геометрия поз из приложения с продолжением предплечья ниже границы ячейки. Голова подогнана к круглому вороту: борода естественно перекрывает шею.

PNG-превью собраны и визуально проверены. Браузер был недоступен, поэтому HTML-превью в браузере не проверяли.

## Подключение

Набор подготовлен для подключения. Список соперников, настройки боя и регистрация графики в основном приложении этой задачей не изменялись. При подключении нужно добавить `vitalik` в загрузчик и список соперников, прописать фон `bg_gym`, перенести параметры головы и шеи из `rig.json` и проверить все позы в сцене игры.

Экспорт: `export-sprites.ps1`. Статические превью: `render-contact-sheets.ps1` и `render-scenes.ps1`.
