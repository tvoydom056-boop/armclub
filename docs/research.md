# Ресёрч: армрестлинг-кликер по мотивам Punch Club

> Собрано 2026-10-02. Разделы 1–6 — что уже найдено (источники внизу), раздел 7 — что ещё нужно собрать.

## 1. Игры-референсы

| Игра | Суть | Берём | Не берём |
|---|---|---|---|
| **Punch Club** (2016), **Punch Club 2: Fast Forward** | Менеджер бойца: тренировки → статы (сила / ловкость / выносливость) → бои-автобаттлы → лиги | Три стата; три ветки навыков (Медведь / Тигр / Черепаха → у нас Хук / Топролл / Пресс); лиги-локации; пародийные персонажи; выбор навыков перед боем | Ежедневное падение статов (самая ненавистная механика, в PC2 убрали); голод / сон / настроение — не для MVP |
| **Burrito Bison: Launcha Libre** | Короткий забег → монеты → апгрейды → забег дальше | Петля «сессия → монеты → апгрейд»; уровни у апгрейдов; звезда за каждую покупку, 20 звёзд → бесплатная пиньята (+ пиньята раз в 3 ч); коллекция «особых мармеладок» с описанием и ценой (скрин 2) | — |
| **Arm Wrestle Simulator** (Roblox, 2023) | Прямой конкурент: кликер армрестлинга | Тренировка по частям тела (бицепс / кисть / костяшки + кардио в idle); ребёрты (prestige); боссы по мирам | Голую инфляцию чисел (до e100+) вместо скилла; петов |
| **Arm Wrestling Reborn** (Steam, 2021) | Мэшинг кнопок + 4 техники (Pull, Top Roll, Power Press, Soul Hold), карьера из 6 соперников | Доказательство, что «мэшинг + техники» работает; контроль давления («не сломай руку») | Камеру из-за плеча — у нас 1-е лицо |
| **Arm Wrestling** (Nintendo, 1985) / **Punch-Out!!** | Аркада: соперник лицом к игроку, у каждого характер | Паттерны соперника с «телеграфом» — игрок учит соперника, а не только качает цифры | — |
| **Clicker Heroes** (изучить) | Кликер с активными скиллами | Активные способности на кулдаунах поверх кликов | — |

**Вывод:** армрестлинг-кликеры есть, но они либо про голые числа (Roblox), либо с камерой из-за плеча (Reborn). Связки «вид от 1-го лица + реальные техники + карьера в духе Punch Club» не нашёл.

## 2. Армрестлинг: предметная область

### 2.1 Правила → механики

| Правило (WAF / East vs West) | Механика в игре |
|---|---|
| Захват ладонь к ладони, костяшки больших пальцев видны, запястья прямые, свободная рука на пеге. Нет захвата за 30 с → судейский захват | Анимация захвата перед раундом; судейский захват как штраф |
| Старт по «Ready… Go!», движение раньше — фальстарт | Клик до «Go» = предупреждение |
| 2 предупреждения = фол, 2 фола = проигрыш раунда | Как есть |
| Фол в проигрышной позиции = сразу проигрыш раунда (EvW) | Нельзя «сфолить, чтобы спастись» |
| Локоть ушёл с пэда, плечо за центральной линией = фол | Позже, в системе техник |
| Срыв захвата (slip) → перезахват, при повторе — матч на ремне | Шанс срыва зависит от хвата; «Магнезия» снижает |
| Пин: кисть соперника касается пин-пэда | Победа в раунде при `position = +1` |
| Опасная позиция (локоть уходит за линию плеча) → риск перелома | Механика риска и травмы (позже) |
| WAF: рабочее плечо выше стола → King's Move фактически запрещён | Лиги с разными правилами: в подвале можно всё |
| Супер-матч: до 3 побед (bo5), титульный — до 4 (bo7), 60 с отдыха | Раунды + выбор усиления в перерыве |

### 2.2 Силовые компоненты → статы и апгрейды

| Компонент | Что это | Где решает |
|---|---|---|
| Пронация | Поворот предплечья ладонью вниз, от себя | Топролл |
| Супинация | Поворот ладонью вверх, к себе | Хук |
| Каппинг | Сгибание кисти к предплечью | Хук, контроль запястья |
| Райзинг | Подъём кисти и костяшек над рукой соперника | Топролл, хай-хук |
| Бэк-прешер | Тяга руки к своему плечу | Почти везде |
| Сайд-прешер | Давление вбок, к пин-пэду | Добивание |
| Пальцы / хват | Удержать кисть соперника или раскрыть его пальцы | Топролл |
| Бицепс | «Сырая» сила сгибания | Хук |
| Трицепс, плечо, вес тела | Давление сверху | Пресс |
| Выносливость | Сколько держишь нагрузку | Затяжные матчи, King's Move |
| Взрывная сила | Реакция и мощность на «Go» | Флеш-пин |

### 2.3 Техники

- **Хук** — «внутренняя» техника: супинация, каппинг, бэк-прешер; борешься с рукой соперника, а не с кистью. Держится на запястье и бицепсе.
- **Хай-хук** — хук высоко на кисти; защита от топролла через борьбу за верх кисти.
- **Топролл** — «внешняя»: пронация, райзинг, скольжение к пальцам соперника и раскрытие его кисти. Берёт рычагом, а не голой силой.
- **Пресс** — разворот корпуса, плечо за кистью, трицепс, плечо и вес тела. Добивание из нейтральной или выигрышной позиции.
- **King's Move** — оборона снаружи: райзинг, пронация, тяга, оба плеча ниже стола. Сам не выигрывает, но атаки против него не работают; соперник устаёт → переход в пресс. Популяризовал Michael Todd.
- **Переходы**: сильный хук → пресс или контр-топролл; проседающий топролл → защитный хук.

### 2.4 «Треугольник техник» (скрин 4)

```
                     H1 High Hook
                    /            \
          H2 Hook & Drag      T1 Posting Toproll
            /                        \
    H3 Hook & Drive             T2 Sweeping Toproll
          /                              \
  P1 Shoulder Press                T3 Low-hand Toproll
        /                                  \
  P2 Flop Press                        T4 Open Toproll
      /______________________________________ KM King's Move
```

Наша трактовка (проверить по видео):
- левая сторона — «внутренняя» ветка (хук → пресс), правая — «внешняя» (топролл → King's Move);
- вершина — самая высокая и нейтральная позиция кисти; чем ниже узел, тем ниже и рискованнее позиция;
- для игры это **граф состояний**: соседние узлы связаны переходами, у каждого узла — требования к статам и контры.

⚠️ Первоисточник схемы не найден. Текстовых описаний вариантов (posting / sweeping / low-hand / open toproll, hook & drag / drive, shoulder / flop press) в сети почти нет — нужен видео-ресёрч (раздел 7).

### 2.5 Геометрия вида от 1-го лица (правая рука)

- Захват ладонь к ладони: тыльная сторона кисти соперника смотрит влево от нас → **побеждаем, укладывая руки влево, проигрываем — вправо**.
- Наш локоть чуть правее центра у нашего края стола, его локоть — чуть левее центра у его края; замок кистей над центром.
- Наше предплечье входит в кадр снизу (как руки в ретро-шутерах), его предплечье — сверху, от торса.
- ⚠️ Перспективу и наклон проверить на POV-видео.

## 3. Математика кликера

- Цена следующего уровня: `cost = base × rate^owned`; n уровней сразу: `base × rate^owned × (rate^n − 1) / (rate − 1)`.
- Пример из статьи: у ларьков с лимонадом в AdVenture Capitalist `rate = 1.07`. Начнём с ~1.15 и подгоним в таблице.
- Цены растут экспоненциально, доход — линейно (× множители) → неизбежные «стены» → prestige (сброс с бонусом). Prestige-валюта растёт медленнее основной, её считают от лучшего или суммарного заработка.
- JS `Number` держит до ~1.8e308 — хватит. `break_infinity.js` — только если уйдём в масштабы e100+.
- Сохранение: JSON в localStorage + номер версии схемы для миграций.

## 4. Game feel

- Посмотреть до фазы визуала: *Juice it or lose it* (Jonasson & Purho, GDC Europe 2012) и *The Art of Screenshake* (Jan Willem Nijman, Vlambeer, 2013).
- Минимальный набор: тряска экрана на рывке, hit-stop на пине, всплывающие цифры силы, частицы (пот, пыль), звук клика с разбросом тона, «дыхание» соперника.

## 5. Арт и пайплайн

- Стиль: мультяшный, как Burrito Bison (решено 2026-10-02). Пиксельные пункты ниже (Dead Cells, Aseprite) — запасной вариант; основной путь — векторные части + скелетная анимация (см. plan.md §6, фаза 5).
- **Риг для MVP**: слои спрайтов (фон, соперник, стол, его предплечье, замок кистей, наше предплечье); предплечья поворачиваются кодом вокруг локтей. Новые кадры нужны только при смене хвата или техники.
- **Под 11 техник**: пайплайн Dead Cells — простая 3D-модель со скелетом → рендер в малом разрешении без сглаживания + тун-шейдер → пиксельные спрайты. Комбинации «моя техника × техника соперника» не рисуются руками.
- Референсы кистей: Handy Art Reference Tool (есть в Microsoft Store), HAELE 3D Hand Poses (Steam).
- Редакторы: Aseprite (платный), LibreSprite, Pixelorama, Piskel (бесплатные).

## 6. Стек

- **Phaser 4** — стабильный с 10.04.2026, актуальная версия v4.1.0 (30.04.2026).
- Официальный шаблон `phaserjs/template-react-ts`: Phaser 4, React 19, Vite, TypeScript; React и Phaser общаются через EventBus и ref на игру и сцену.
- Логика матча и экономики — чистый TS без React и Phaser (тесты на Vitest); состояние — Zustand (vanilla-стор читают и React, и Phaser).
- Туториалов по v4 пока меньше, чем по Phaser 3 → сверяемся с официальной документацией v4.
- Релиз: веб (itch.io, GitHub Pages); позже десктоп или мобилки через обёртку (Tauri, Electron, Capacitor).
