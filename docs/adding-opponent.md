# Как добавить нарисованного соперника

Персонаж со спрайтами — это три вещи:

| Что | Где | Зачем |
|---|---|---|
| Спрайты | `public/art/opponents/<id>/` | картинки |
| Манифест | `src/game/characters/<id>.json` | где у картинок плечо, шея, голова и какого они размера |
| Боец | `src/core/opponents.ts` (`OpponentDef`, состав в `ROSTERS`) | имя, баланс, место в карьере |

Других мест нет: список бойцов со спрайтами, фоны и портрет в хабе собираются из манифестов (`src/game/characters.ts`).

## 1. Спрайты

Все файлы рисуются по шаблонам существующих бойцов (у всех одинаковые размеры и положение частей тела).
Разрешение может быть больше — сцена приводит картинку к шаблону, — но пропорции должны совпадать.

| Файл | Шаблон | Что важно |
|---|---|---|
| `torso_motion.png` | 1572×1001 | торс без головы и рабочей руки, с обрубком шеи сверху |
| `head_{calm,strain,telegraph,tired,lose,win,press}.png` | 600×700 | все 7 лиц в одной позиции: голова не должна прыгать при смене мимики |
| `arms_motion.png` | ровно 1670×941 | сетка 3×3, 9 поз от его победы до его поражения; кадры совмещены по точкам `ARM_POSES` (`src/game/armMotion.ts`) — рисовать поверх листа Йоса или Бори |
| `arm_free.png` | 560×620 | свободная рука; кулак со штырём на том же месте, что у всех (штырь в точке 501, 493) |
| `cuff.png` | 151×151 | только если стык рукава с торсом виден (сейчас — у Бори) |
| `<фон>.png` | 1280×720 | необязательно; иначе общий подвал |

## 2. Манифест

Скопируй манифест похожего бойца или открой игру в dev с `?rig=<id>` — редактор предложит создать
манифест из `boris.json`. Все точки — в px шаблона своей картинки (их видно в любом редакторе картинок):

- `torso.shoulder` — точка торса, куда входит рукав рабочей руки; торс стоит ею на плече листа рук.
- `torso.neck` — середина шеи торса, куда встаёт голова.
- `torso.freeShoulder` — откуда растёт свободная рука.
- `head.neck` — низ шеи на картинке головы; `head.fade` — если обрубок шеи шире шеи торса и ложится
  на одежду прямоугольником, низ головы плавно растворяется между этими строками.
- `torso.scale`, `head.scale`, `freeArm.scale` — px сцены на px шаблона; `arms.scale` — размер связки рук.
- `arms.drop`, `arms.sag` — опустить захват целиком / опускать кулак на пути к нашему штырю.
- `bg` — имя фона в папке бойца, `cuff` — накладка на стык, `bust` — голова на карточке в хабе (em).

## 3. Подгонка в редакторе рига

`npm run dev`, открыть `http://localhost:5173/?rig=<id>`:

1. Включи «Эталон: boris» — поверх рисуется полупрозрачный Боря на том же плече.
   Макушка, подбородок и линия плеч нового бойца должны быть примерно там же.
2. Тяни кружки: «Торс» — тело вверх-вниз по плечу руки, «Шея» — голову по торсу, «Св. плечо» — свободную руку.
   Масштабы и точные числа — полями справа.
3. Проверь пин −1, 0, +1, все лица и технику «press» (корпус наклоняется): не должно быть щелей
   между рукой и рукавом, торчащего обрубка шеи, головы под шкалой пина.
4. «Сохранить» пишет `src/game/characters/<id>.json`.

## 4. Проверка

`npx vitest run` — `tools/characters.test.mjs` проверяет у каждого манифеста: все файлы на месте,
размеры по шаблонам, точки внутри картинок. Потом бой с бойцом в игре.
