# Правила для агентов (Codex / GPT)

Игра про армрестлинг на React + Phaser. Язык интерфейса, комментариев и документов — русский.

## Спрайты бойцов — обязательно

Перед генерацией или правкой любого спрайта бойца прочитай [docs/sprite-spec.md](docs/sprite-spec.md): §0 (единый стиль) и §2 (порядок генерации).

1. **Эталон один — Дядя Боря** (`public/art/opponents/boris/`). Каждый спрайт торса и рук рисуется **правкой файла Бори**: это изображение 1, edit target.
   Концепт бойца (изображение 2) — источник только для лица, цветов и одежды. Спрайты других бойцов как исходник не брать.
2. **Культя и руки — по контуру Бори.** Рукав рабочей руки, плечо на торсе, свободная рука и все 9 кадров `arms_motion` повторяют Борин силуэт.
   Меняется только заливка внутри контура: ткань, кожа.
3. **Рукав обязателен.** Нельзя: майку без рукавов, голое плечо, широкий рукав. Руки не толще Бориных, без вен и вздутых мышц.
4. В каждый промт торса и рук вставляй стиль из [art-brief.md §1](docs/art-brief.md) и блок **STYLE LOCK** из sprite-spec §0 дословно.
5. Головы: `head_calm` — правка `boris/head_calm.png`. Остальные лица — правка **нового** `head_calm`, меняется только мимика.
6. Холсты, имена файлов и точки крепления — по таблице sprite-spec §1. Фон прозрачный (настоящая альфа).

## Проверка перед сдачей

```
node tools/makeSpriteGuides.mjs
npx vitest run tools/characters.test.mjs --reporter=verbose
```

Ошибок быть не должно. Для нового бойца не должно быть и предупреждения «Контур культи не по Боре».
Если оно есть, перерисуй файл. Порог проверки не трогай.
Глазами: dev-сервер, `?sheet=<id>` — лист поз, `?rig=<id>` — подгонка точек. Подробности в [docs/adding-opponent.md](docs/adding-opponent.md).
